Pengenalan Layanan

REST API untuk City Courier — aplikasi kurir & pengiriman on-demand. Digunakan oleh:
• Aplikasi Kurir (Flutter) — manajemen order, lokasi GPS, dompet, penarikan dana.
• Aplikasi Pelanggan (Flutter) — buat pengiriman, lacak paket, pembayaran.

Lihat spesifikasi lengkap (OpenAPI 3.0): openapi.yaml

Autentikasi — Laravel Sanctum

Headers wajib
Authorization: Bearer {token_sanctum}
Accept: application/json

Dapatkan token melalui POST /verify-otp, POST /auth/google, POST /auth/phone, atau POST /register-kurir. Beacon public (geocoding, tracking, drop-points, callback) tidak memerlukan token.

Konvensi Response & Pagination

Envelope Standar
"success": true // | false
"message": "..."
"data": { ... }   // payload
"errors": { ... }  // hanya 422
Pagination (Laravel)
"data": [ ... ],
"current_page": 1,
"last_page": 12,
"per_page": 15,
"total": 175,
"next_page_url": "...page=2"

Catatan: Endpoint public tidak menuntut token. Validasi gagal → HTTP 422 dengan objek errors per-field. Tidak terautentikasi → HTTP 401.
